# Sprint_7 — QA-тестирование API сервиса заказа самокатов «Яндекс.Практикум»

Проект содержит автоматизированные тесты для API учебного сервиса
заказа самокатов: **https://qa-scooter.praktikum-services.ru/**

Документация API: https://qa-scooter.praktikum-services.ru/docs

## Что покрыто тестами

### Основное задание

**1. Создание курьера (`POST /api/v1/courier`)**
- курьера можно успешно создать;
- нельзя создать двух одинаковых курьеров;
- для создания курьера обязательны все поля (`login`, `password`);
- запрос возвращает корректный код ответа;
- успешный запрос возвращает `{"ok": true}`;
- при отсутствии обязательного поля возвращается ошибка;
- при создании курьера с уже существующим логином возвращается ошибка.

**2. Логин курьера (`POST /api/v1/courier/login`)**
- курьер может авторизоваться;
- для авторизации нужно передать все обязательные поля;
- при неверном логине/пароле возвращается ошибка;
- при отсутствии одного из полей возвращается ошибка;
- при авторизации несуществующего пользователя возвращается ошибка;
- успешный запрос возвращает `id`.

**3. Создание заказа (`POST /api/v1/orders`)** — с параметризацией:
- можно указать цвет `BLACK`;
- можно указать цвет `GREY`;
- можно указать оба цвета;
- можно не указывать цвет совсем;
- тело ответа содержит `track`.

**4. Список заказов (`GET /api/v1/orders`)**
- тело ответа содержит список заказов (`orders`).

### Дополнительное задание

**5. Удаление курьера (`DELETE /api/v1/courier/{id}`)**
- успешный запрос возвращает `{"ok": true}`;
- неуспешный запрос возвращает соответствующую ошибку;
- запрос без `id` возвращает ошибку;
- запрос с несуществующим `id` возвращает ошибку.

**6. Принять заказ (`PUT /api/v1/orders/accept/{id}`)**
- успешный запрос возвращает `{"ok": true}`;
- отсутствие `id` курьера — ошибка;
- неверный `id` курьера — ошибка;
- отсутствие `id` заказа — ошибка;
- неверный `id` заказа — ошибка.

**7. Получить заказ по номеру (`GET /api/v1/orders/track`)**
- успешный запрос возвращает объект с данными заказа;
- запрос без номера заказа — ошибка;
- запрос с несуществующим номером — ошибка.

## Стек

- Python 3.10+
- pytest
- requests
- allure-pytest

## Установка и подготовка окружения

```bash
git clone <ссылка-на-репозиторий>
cd Sprint_7

python -m venv venv
source venv/bin/activate        # для Windows: venv\Scripts\activate

pip install -r requirements.txt
```

Также потребуется установленный **Allure CLI** для генерации html-отчёта:

```bash
# macOS
brew install allure

# Linux (пример через npm)
npm install -g allure-commandline --save-dev
```

## Запуск тестов

Запуск всех автотестов с одновременным сбором данных для Allure:

```bash
pytest -v --alluredir=allure-results
```
Запуск тестов конкретной ручки, например «Создание курьера»:

```bash
pytest tests/test_create_courier.py -v --alluredir=allure-results
```

## Посмотреть отчет Allur

allure serve allure-results
